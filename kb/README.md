# Northwind Dental — knowledge base

The documents the agent answers from. A fictional practice, written to look like something a real
one would hand over: uneven in depth, occasionally repetitive, and silent on plenty.

The silences are deliberate. An agent that answers everything has not been tested — the
interesting behaviour is what it does when the answer genuinely is not here. Things no document
covers, and which the eval suite checks it declines rather than invents:

- prices for anything not on the fees page
- whether a specific treatment is right for a specific person
- anything clinical: diagnosis, medication, whether something will hurt
- insurance claims, refunds, complaints
- the dentists' individual qualifications or availability
